# Start here

1. Make sure Node.js and Claude Code are installed (`node -v` and `claude --version` both show a number).
2. Make a fresh folder: `mkdir ~/supplock && cd ~/supplock`
3. Put this `design_handoff_supplock` folder inside `~/supplock`.
4. Run `claude`.
5. Type: `Read design_handoff_supplock/PROMPT.md and follow it.`
6. Do one step at a time. Say "done" after each one.
